# /brag-slim plan v2: an OS that becomes a game

## Angle
User direction: "feel like an OS and then switch to being a game", opening on "a pixelated computer booting up the OS".

The video mirrors itself:
1. Pixels boot the OS.
2. The OS runs like a real desktop.
3. Inserting the cartridge pixelates the OS back into a game.

## Storyboard (25.0s, 1920×1080, 30fps)
| Time | Scene | Sound |
